A lesson: the index was the gap

An agent was asked about earlier work on a topic. It did not find it, and searched the web instead. The files were on disk the whole time. The rules were fine. The chat summary had lost the topic after compaction. Nothing pointed from the topic to the folder.

The fix had two parts:

  1. A hook builds a work index at session start and before compaction. One row per folder: name, first heading, linked backlog item, newest date. No model, no network. It drops any line shaped like a key.
  2. A rule: search local files first, then the web.

working The hook is installed. The index file was rebuilt at the start of the session that built this site (2026-10-30).
