Review surfaces lane

The owner does not review work in a terminal. Every report, plan or draft meant for the owner becomes an HTML page.

Why pages, not chat

  • A page can hold a diagram, a table and evidence on one screen.
  • The owner can mark a sentence and leave a note on it.
  • The note goes back to the agent that wrote the page. The agent fixes the page and asks again.

The house rule says it in one line: anything the owner reviews is an HTML page, opened in the review tool. A Markdown report is not an exception.

How one review round works

agent writes page.html
  → review tool opens it for the owner
  → owner marks text, writes notes
  → notes go to the agent's inbox
  → agent edits page.html, asks again
  → owner ends the review, or approves
