# LLMwiki (plain files) before RAG

Claim: Plain-file notes (an LLMwiki) stay the default memory until roughly a hundred
sources; move to RAG only when search and scale demand it, never by default.

Evidence: "It says plain files work up to about a hundred sources, which gives your
non-technical friends a real number." The second brain (62 notes) is the working
instance; nothing here needs a database yet.
