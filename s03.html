Crews lane: scouts and ships

A crew is one worker agent on one task. There are two kinds.

Scout

Finds facts. The output is a written report. Nothing is pushed. The worktree is thrown away after.

Ship

Changes code. The output is a pull request or a local merge. The owner says when it merges.

The life of one task

The completion gate

Upstream Firstmate treats an owner decision as a task that waits for the owner. A worker does not close a task while such a question is open. It asks the supervisor to record the question first. When nothing waits on the owner, the worker runs one command that says so. The design is in upstream docs/captain-hold-lifecycle.md.

  5. Opened the index page in a review tool for the owner.
