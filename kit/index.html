Rules

  1. No colour values outside tokens.css.
  2. One display font, one body font. Mono only for code.
  3. Light and dark use the same token names.
  4. Yellow (pop) only for what needs the user.
  5. A status always shows a colour and a word.
  6. Three button kinds, 44px tall. A header has at most 3 links.
