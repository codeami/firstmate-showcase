Authority · from the operating manual, version 0.5

Cast and authority

The setup has an operating manual. It defines authority, not behaviour: who may do what, and who must ask first.

Marks: verified = checked on disk or in a running process · designed = written down, not shown to work. The manual's own status is "designed, not proven".

Two engines

The manual splits the work between two engines. A software engine does code: branches, worktrees, crews. A staff engine would do the board, the inbox, the calendar and publishing.

The software engine runs today: verified.

The staff engine has not run: designed.

A role is a seat, not a bot. One bot may hold two seats until the volume of work justifies two bots.

Rules that travel with the business seats

  • CMO: evidence or silence. A market size with no source is not a market size. Every recommendation names what would prove it wrong.
  • CPO: compare designs with real products. A feature with no user problem behind it is argued against. Design waits until the market question is closed.
  • CFO: a number without its assumptions is not a number. Model the downside first. Runway, price and cost base are owner inputs, never invented.

The autonomy ladder

LevelMeaning
A0Observe only.
A1Draft. The draft waits in Review for the owner.
A2Act on internal state, alone.
A3Act outside: send, publish, spend, merge. Only the owner holds A3.

"Ask" is not a level. It means: propose one specific action, then wait for the owner's word. A3 is never given to a role. The owner grants it to one approved action, once.

Seven invariants

  1. A3 is never granted to a role.
  2. The board is the only queue.
  3. One owner per card.
  4. No card leaves Review without the owner's word.
  5. Staff roles hold no code-write access.
  6. No live calls between the two engines. One-way delivery is allowed.
  7. No completed charter, no run.

Permission posture today

A model-reviewed mode is being trialled. It is not the default yet.

verified Every worker the software engine starts skips permission checks. This is the standing default when no mode file exists. On 2026-10-31, the mode file did not exist, and all 10 running Claude worker sessions carried the bypass flag.

designed One line in one local file switches every later launch to a model-reviewed mode. In that mode, a model reviews each tool call. That mode depends on a separate settings block that is still under review. Until the switch is on, the manual's target deny rules (no push, no edits to .git) are not in force for scouts. How this was checked is on Testing in public.
